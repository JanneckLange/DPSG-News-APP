description: Review Flutter code quality, UX, accessibility and maintainability.

---

Review only Flutter-related changes.

Do not modify code.

Evaluate:

## Architecture

- separation of concerns
- widget composition
- state management
- unnecessary complexity

## UI

- consistency
- spacing
- typography
- theme usage
- responsive layout

## Accessibility

- semantics
- touch targets
- contrast
- text scaling
- reduced motion

## UX

- loading
- empty
- error
- offline
- success feedback

## Performance

- unnecessary rebuilds
- widget structure
- large lists
- image usage

Classify findings as:

- High
- Medium
- Low

Finish with the three most valuable improvements.
